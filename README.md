# Commedia

A roguelike Dante game: a solo maze through one book. Walk, play your hand against what you can't see, and find the hole.

All three chapters (Inferno, Purgatory, Paradise), the cards, the dice, the rules and the Pilgrim's Ledger are inside one web page. It needs no account and sends nothing anywhere.

**Play:** https://1980finbar.github.io/Commedia/

## Download (computers)

[Commedia.zip](https://1980finbar.github.io/Commedia/Commedia.zip) holds the whole game in one file that plays with no internet: unzip it and double-click `Commedia.html`. iPhone and iPad cannot open a loose file; use the web address and Add to Home Screen, below.

## On a phone or tablet

Open the address once while online, then:

- iPhone or iPad (Safari): Share, then Add to Home Screen.
- Android (Chrome): the menu, then Install app (or Add to Home screen).

From then on it opens like an app and plays with no connection. A run you leave in the middle is saved on that device, in that browser; clearing the browser's site data erases it, and the Ledger with it.

- `Commedia.zip`: the download for computers
- `sw.js`, `manifest.webmanifest`, the `.png` icons: what a phone needs to keep it and run it offline
